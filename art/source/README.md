# Nightfall Art Sources

Non-runtime art sources, explorations, and review records. Nothing in this directory is loaded by the client.

- `explorations/` contains unapproved visual studies and their exact prompt record.
- Approved lossless masters will receive a separate `approved/` location only after passing the technical asset contract.
- Runtime derivatives belong under `packages/client/public/art/` and must be selected through the explicit client art registry.

Do not treat an exploration as canon merely because it is checked into the repository.
