# Product Horizon

**Status:** Locked  
**Last updated:** 2026-07-17

Friends-hosted “done enough that I’m proud to host it” — not a commercial launch checklist.

## Must ship

1. **Haven building web** — named town; buildings with distinct benefits; player-chosen unlock order; resource sinks from expeditions.
2. **Deep craft** — gear + spell/scroll fusion with sliding risk ladder (soft tradeoffs → hard curses / bricks).
3. **Events** — narrative/mechanical nodes (survivors, resources, rumors, hard choices).
4. **Co-op multiplayer** — 2–3 heroes, 1–3 humans on one run; lobby ownership (humans may control multiple); visible ally hands; no AI allies; PvE only.
5. **At least 3 classes with subclasses** — real kits (6-class roster is stretch).
6. **Party expedition loop** — Gates + Approach/Delve/Return; waypoints expand the world; town pillars are Haven HP; combat puzzle with intents + initiative; medium+ runs.
7. **Roster + Legacy Scars** — DD-like attachment; Haven can permanently fail at 0 pillars; scars carry forward.
8. **Async presence (light)** — each friend has their own Haven on the host; **list + peek** (read-only). Visit/gifts/ghosts can wait.

## Nice later

- Full 6-class roster + deep subclass web
- Richer async (gifts, ghost parties, Haven visits)
- Distinct enemy/ecology per level band at Frontier (Band 1) quality or better
- Stronger art / VFX / audio (placeholders OK for must-ship if atmosphere reads)

## Dream

- Large content volume (many events, boss variants, seasonal Gloom pressures)
- Elaborate Haven simulation
- Spectator / replay tools

## Explicit non-goals

- Commercial monetization / live ops
- PvP
- Steam (or any store) as a requirement
- Reopening the locked tech stack without an explicit revisit ([tech-decision.md](tech-decision.md))

## Fun priority (when systems conflict)

1. In-combat tactics and combos  
2. Buildcraft + risk/reward (pathing and craft)  
3. Haven growth
