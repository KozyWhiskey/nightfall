# Band 1 — Frontier (forest fringe template)

**Status:** Draft  
**Last updated:** 2026-07-17  
**Name pool:** Whisperwood · Murkwood · Blackcopse · Hushweald  
**Axis:** Level-band ecology for Gates — **not** an expedition leg. Legs are Approach → Delve → Return (see [../../loops/run-structure.md](../../loops/run-structure.md)).

## Identity

- **Fantasy:** Whisperwood-like Gloom-fringe woods where Haven’s first expeditions learn the dark: black-barked trees, sickly fungi, shifting paths, and voices stolen from memory.
- **Role:** Onboarding / low Gate; teach intents, pathing, Safe craft, first Segment Boss / first waypoint.

## Ecology

Mist, fungal undergrowth, husks of animals, lantern-shy fauna, and old Way-lantern ruins. Enemies telegraph clearly. Flavor lines swap with the rolled name (e.g. Hushweald stresses silence; Blackcopse stresses dense dead timber).

## Mechanics summary

- Lower elite weight; more rest/event nodes on Approach/Delve
- Loot budgets modest; scrolls mostly unlearned (Safe fuse teaching)
- Delve boss teaches **reading and disrupting a powerful telegraphed intent**, then waypoint claim + waypoint **chest** + Ember Shard pillar choice
- The first boss/waypoint reward guarantees a **ruined-settlement trace**, proving that exploration can unlock future people, schools, blueprints, or item families.
- Return leg: short pressure, no boss

## Progression / unlocks

- Available as the **only** starting Gate from a fresh Haven
- Clearing Delve boss claims waypoint (map growth; does not auto-restore a town pillar)
