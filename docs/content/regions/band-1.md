# Band 1 — Frontier (forest fringe template)

**Status:** Draft  
**Last updated:** 2026-07-17  
**Name pool:** Whisperwood · Murkwood · Blackcopse · Hushweald  
**Axis:** Level-band ecology for Gates — **not** an expedition leg. Legs are Approach → Delve → Return (see [../../loops/run-structure.md](../../loops/run-structure.md)).

## Identity

- **Fantasy:** Gloom-fringe woods where Haven’s first expeditions learn the dark.
- **Role:** Onboarding / low Gate; teach intents, pathing, Safe craft, first Segment Boss / first waypoint.

## Ecology

Mist, fungal undergrowth, husks of animals, lantern-shy fauna. Enemies telegraph clearly. Flavor lines swap with the rolled name (e.g. Hushweald stresses silence; Blackcopse stresses dense dead timber).

## Mechanics summary

- Lower elite weight; more rest/event nodes on Approach/Delve
- Loot budgets modest; scrolls mostly unlearned (Safe fuse teaching)
- Delve boss teaches **waypoint claim** + waypoint **chest** + Ember Shard pillar choice
- Return leg: short pressure, no boss

## Progression / unlocks

- Available as the **only** starting Gate from a fresh Haven
- Clearing Delve boss claims waypoint (map growth; does not auto-restore a town pillar)
