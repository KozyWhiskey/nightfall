# Bosses

**Status:** Stub  
**Last updated:** 2026-07-17

Each **level band** needs at least one Segment Boss (Delve climax) that:

- Teaches a new mechanic or spikes an old one
- Drops meaningful craft/loot
- On victory, **claims a Waypoint** (map growth — does not auto-restore a town pillar)

Bosses belong on the **Delve** leg — not on Approach or the Return leg.
