## School law (locked)

- Every class starts with **exactly two** schools and can learn only from schools it knows.
- Each class must have **≥2** schools it can develop in (satisfied by the starter pair; subclass adds a third).
- **Subclass** opens a **third school** (choice depends on which subclass is taken).
- Cross-school craft reactions require knowing both schools — see spellcraft.

Stretch / later: Dawnkeeper, Technomancer, Gloom Warden (names from prototype — not locked). Assign two starters + subclass thirds when those classes are briefed.
