# Event: The Returning Echo

**Status:** Accepted Build 1 Return-event definition
**Event ID:** `returning_echo`
**Region tags:** `unlit_road`, `return`, `memory_horror`
**Last updated:** 2026-07-20
**Related:** [The Unlit Road](../expeditions/the-unlit-road.md), [Vertical-Slice Tuning](../expeditions/vertical-slice-tuning.md)

## Setup

On the road home, the party hears an answer to one choice they made earlier in the expedition. The presentation selects a remembered source—Courier, Waystation, Choir, or Ember Pit—from resolved run flags, but its mechanical choices never reroll or alter prior facts.

## Choices

| Choice | Exact result |
|---|---|
| Follow the fading lamps | Reduce Run Gloom by 8. |
| Take the roadside cache | Gain 2 Salvage and 1 Emberglass; add 6 Run Gloom. |
| Claim the remembered pattern | Add 4 Run Gloom; present one identified Imbued scroll offer. The player may take or leave it. |

The event resolves before the final edge to Haven. Its Gloom changes therefore affect the successful-Return Haven-Gloom result. It grants no combat and cannot create a second boss.

## Content rules

- `returning_echo` is the only Build 1 Return Event.
- Its remembered-source copy is presentation derived from already-resolved flags; no LLM or new gameplay random roll participates.
- Every result is visible before confirmation, including the Gloom consequence and the fully identified scroll offer.
