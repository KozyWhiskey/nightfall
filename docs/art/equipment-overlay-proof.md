# Vanguard equipment-overlay proof

**Status:** In progress — attachment data defined; dedicated overlay-source alignment is next.

The proof uses the new transparent Vanguard base at `992 × 1152`. It has two normalized attachment centres: `mainHand` `(0.307, 0.497)` for the lowered screen-left fist and `offHand` `(0.680, 0.428)` for the raised screen-right fist.

No gameplay data or normal production standee consumes this proof data.
