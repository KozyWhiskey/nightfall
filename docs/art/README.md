# Nightfall Art Direction

Build 1 visual direction and production guidance. These documents translate the locked creative direction into assets that remain readable in the current DOM client.

## Authority and workflow

1. [Visual Style Bible](visual-style-bible.md) owns the shared visual language.
2. [Technical Asset Contract](technical-asset-contract.md) owns framing, delivery, orientation, and runtime readability requirements.
3. [Prompt Library](prompt-library.md) owns reusable generation language. Prompts never override content IDs or mechanics.
4. [Asset Manifest](asset-manifest.md) is the production inventory and approval record.
5. [Client Integration Reconciliation](client-integration-reconciliation.md) records the implementation work required before generated assets replace placeholders.

The first four anchor explorations were reviewed together on 2026-08-01, locking the shared visual direction. They remain source studies, not approved runtime assets; individual production files still require manifest approval under the technical asset contract.

## Build 1 production decision

Build 1 begins with precomposed class standees and ID-keyed item illustrations. Full nine-slot hero compositing is not a dependency. A later proof may test main-hand and offhand overlays against one Vanguard pose; expansion requires that proof to pass the technical asset contract at runtime sizes.
