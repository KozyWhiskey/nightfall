# Spec-approved implementer (Cursor Automation)

**Trigger:** GitHub label `spec-approved` added on a PR  
**Repo:** KozyWhiskey/nightfall  
**Tools:** PR comments, memories on

## Instructions

The labeled PR contains an approved change-spec. Implement only that spec on the PR branch.

Stay in the spec's package touch list. Add or fix Vitest fixtures. Run `pnpm check`. Comment the test results on the PR. Do not expand into new capabilities or Decision Register edits unless the spec requires them.
